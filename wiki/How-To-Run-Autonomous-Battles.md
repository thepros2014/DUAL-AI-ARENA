# ⚔️ How to Run Autonomous Battles (Gladiator Mode)
**Auto-Handoff Execution, Turn Bounds & Multi-Model Consensus**

---

## 🤖 1. Autonomous Gladiator Mode (Auto-Handoff)

1. Once your challenge is loaded, click **"Enter Arena"**.
2. Toggle the **"AUTO HANDOFF"** switch in the control bar to **ON**.
3. Red Team begins **Turn 01 (Attack)**:
   - Identifies security vulnerabilities and writes exploit reports into `breakage/`.
4. The system burns context memory and automatically passes file diffs to Blue Team for **Turn 02 (Defense)**:
   - Implements cryptographic patches and unit tests in `working/`.
5. The cycle repeats autonomously until all vulnerabilities are resolved or the maximum round limit is reached.

---

## 🖐️ 2. Manual Step Mode

If you prefer granular control over each AI turn:
1. Leave **"AUTO HANDOFF"** toggled to **OFF**.
2. Click **"Run Red Team Attack"** to execute a single offensive turn.
3. Review the diffs and vulnerability reports.
4. Optionally enter custom prompt directives (e.g. *"Focus specifically on race conditions"*).
5. Click **"Run Blue Team Patch"** to execute the defense turn.
