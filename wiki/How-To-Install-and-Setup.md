# 📖 How to Install & Set Up DUAL-AI-ARENA
**Step-by-Step Installation, Prerequisites & Native Windows Launch**

---

## 📋 1. System Requirements & Prerequisites
- **Operating System**: Windows 10 (64-bit) or Windows 11.
- **Runtime**: [Microsoft Edge WebView2 Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) *(Pre-installed on modern Windows 10/11)*.
- **Hardware**: 4 GB RAM minimum (8 GB+ recommended for local Ollama models).

---

## 📥 2. Installation Methods

### Option A: 1-Click GUI Setup (Recommended)
1. Download **`DualAI-MID-Arena-Setup.exe`** (or **`DualAI-MID-Arena-Free-Setup.exe`**).
2. Double-click the installer executable.
3. Click **"Install Now"**.
4. The setup installs the application for the current Windows user, registers shortcuts, and launches the Arena.

### Option B: Offline Installer ZIP
1. Extract `DualAI-MID-Arena-v1.0.0-Windows-Installer.zip`.
2. Run `Setup.bat` with standard user privileges.

### Option C: Portable Standalone ZIP
1. Extract `DualAI-MID-Arena-v1.0.0-Windows-Portable.zip`.
2. Double-click `DualAI.Arena.exe` to run immediately without installation.

---

## 📜 3. Initial Digital Agreement Sign-Off
1. On first launch, enter your **Name/Organization** and **Email**.
2. Click **"ACCEPT, DIGITALLY SIGN & ENTER ARENA →"**.
3. Your agreement is stored in the application's protected local storage.
