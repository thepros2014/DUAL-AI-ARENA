# Arena tutorials

Learn the Arena by completing a small review from start to finish. These tutorials use a synthetic example, so you can practice without importing a real project.

## Learning path

1. **[[Tutorial-Your-First-Arena-Battle]]** — create a challenge, run one turn at a time, and understand the two teams.
2. **[[Tutorial-Review-and-Test-a-Patch]]** — inspect a proposed change and check it against the original requirements.
3. **[[Tutorial-Review-Your-Own-Project]]** — move from a small example to a focused review of your code.

Allow time for model responses; speed depends on your model, hardware, and provider. Screen labels may vary by installed version. Use the corresponding challenge, provider, team, and results controls in your build.

## Before you begin

- Install and launch the Arena using [[How-To-Install-and-Setup]].
- Configure a provider using [[How-To-Configure-AI-Providers]]. Select a model available in your installation or account.
- For local inference, complete [[Offline-Ollama-Setup]] first. Model downloads require a connection; locally installed models can then be used for local inference.
- Cloud providers receive the inputs sent to them and may charge for requests. Use the synthetic example while learning.

## What the teams do

**Red Team** looks for problems and explains why they matter. **Blue Team** proposes changes to address those findings. Your role is to check the evidence, review the changes, and test the result. Agreement between models is useful feedback, not proof that a change is correct.

## If you get stuck

If no turn starts, check that your selected provider is enabled and available. If a turn fails, read its error before retrying. For slow local responses, try a smaller input and a model your hardware can run. See [[How-To-Troubleshoot-Common-Errors]] for setup issues.

For community help, include your app version, the action you took, and a sanitized error message in [Discussions](https://github.com/thepros2014/DUAL-AI-ARENA-Discussions/discussions).
