# 🔐 How to Access & Use the Admin Console
**Admin Unlocks, Audit Trails, DPAPI Key Rotation & Rate Limit Monitoring**

---

## 🔑 1. Unlocking the Administrative Console

You can access the Admin Console using either of two methods:
- **Keyboard Shortcut**: Press **`Ctrl + Shift + A`** anywhere in the application.
- **Header Gesture**: Double-click the **`// DUAL AI MID ARENA`** logo in the top-left corner of the header.

---

## 🛠️ 2. Capabilities of the Admin Console
- **Historical Match Audit Logs**: Inspect raw JSON battle logs, round timings, and model consensus metrics.
- **Hardware Binding & DPAPI State**: View the SHA-256 machine hash binding your EULA and encrypted data stores.
- **Storage Metrics**: View total disk usage and clean legacy temporary challenge runs.
- **Security Rate Limiting**: Inspect active IP throttles and failed authentication attempts.
