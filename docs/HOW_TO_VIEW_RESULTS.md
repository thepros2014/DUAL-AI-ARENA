# 🔍 DUAL-AI-ARENA — How to View, Inspect & Export Battle Results
**Step-by-Step Guide to In-App Diffs, Breakage Reports, Disk Storage & Code Export**

---

## 📌 Overview
After running an adversarial battle in **DUAL-AI-ARENA**, your results are available through three distinct interfaces:
1. **Live in the Desktop Application UI** (Interactive Diffs, Working Tree, and Breakage Reports).
2. **On Your Local Windows File System** (Encrypted at rest with AES-256-GCM + DPAPI).
3. **Inside the Administrative Console** (`Ctrl + Shift + A`).

---

## 🖥️ 1. Viewing Results Live Inside the Arena UI

When a turn completes, the Arena interface updates with real-time audit panels:

```
┌──────────────────────────────────────┬──────────────────────────────────────┐
│  🔴 breakage/ (Red Team Findings)    │  🔵 working/ (Blue Team Hardened)    │
├──────────────────────────────────────┼──────────────────────────────────────┤
│ - Proof-of-concept exploit markdown  │ - Live patched source code files     │
│ - CWE vulnerability classification   │ - Unit tests generated by Blue Team  │
│ - Exact line numbers & threat vectors│ - Ready-to-deploy clean snapshot     │
└──────────────────────────────────────┴──────────────────────────────────────┘
```

### A. Inspecting the `breakage/` Folder (Vulnerabilities Found)
- In the right sidebar, click on **`breakage/`** to expand the list of discovered security flaws.
- Click any finding (e.g. `VULN-001-TIMING-ATTACK.md`) to open the full vulnerability dossier:
  - **Severity Rating**: `Critical`, `High`, `Medium`, or `Low`.
  - **Vulnerability Title & CWE Code** (e.g., CWE-208 Timing Attack, CWE-89 SQLi, CWE-1321 Prototype Pollution).
  - **Proof-of-Concept Payload**: The exact synthetic attack input generated by Red Team to trigger the bug.

### B. Inspecting the `working/` Folder (Patched Codebase)
- Click on **`working/`** to view all source files that survived the round.
- Click any file to view the syntax-highlighted source code with Blue Team's cryptographic remediation applied.

### C. The Live Diff Viewer & Model Consensus HUD
- Scroll down to the **Model Exchange & Consensus Panel** to see:
  - Line-by-line diffs with additions (`+ green`) and removals (`- red`).
  - The multi-model consensus report (OpenAI, Gemini, and Ollama approval percentages).
  - The live radio commentary transcript explaining the tactical decisions of both teams.

## 📂 2. Accessing Results Stored on Disk (Windows File System)

All workspaces, review histories, and consensus results are persisted in encrypted local application storage.

### Local Windows Storage Location:
- **Full Path**:  
  `C:\Users\<YourUsername>\AppData\Local\DualAI Arena\encrypted-results`
- **PowerShell Environment Variable**:  
  `$env:LOCALAPPDATA\DualAI Arena\encrypted-results`

### Quick One-Liner to Open the Folder:
Press `Win + R`, type the following, and press **Enter**:
```cmd
explorer %LOCALAPPDATA%\DualAI Arena\encrypted-results
```
Or in **PowerShell**:
```powershell
explorer "$env:LOCALAPPDATA\DualAI Arena\encrypted-results"
```

### Folder Structure Inside:
- **`reviews/`**: Contains encrypted JSON records of each battle turn, findings, and consensus scores.
- **`workspaces/`**: Contains the full encrypted snapshots of both `working/` (patched code) and `breakage/` (vulnerability reports).
- **`legal-agreement.enc`**: The signed hardware-bound EULA receipt.
- **`provider-configuration.enc`**: Encrypted API keys and model settings.

> [!NOTE]
> All files on disk are encrypted using **AES-256-GCM** with master keys derived from the **Windows Data Protection API (DPAPI)**, protecting your source code from unauthorized access by other OS accounts or malware.

## 🛠️ 3. Viewing Raw Records in the Admin Console

To inspect raw audit trails and decrypted review records in-app:
1. Press **`Ctrl + Shift + A`** anywhere in the application (or double-click the **`// DUAL AI MID ARENA`** logo in the top-left corner).
2. Enter your administrative credentials.
3. Access the **Audit Trail & Encrypted Store Inspector** to review historical match timestamps, raw JSON payloads, and hardware machine ID bindings.

---

## 📤 4. Exporting Patched Code Back to Your Project

To apply the hardened, verified code back into your production git repository:
1. In the **`working/`** panel, click **"Inspect shared source"**.
2. Click **"Copy File"** or select the code block to copy the hardened implementation.
3. Paste the patched code into your local development branch and run your project's test suite!
